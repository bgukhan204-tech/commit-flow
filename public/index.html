Step 1

Workflow File Exists

Ensure .github/workflows/commit-flow.yml is pushed to your repository (already created!).

Step 2

Enable Workflow Write Permissions

On GitHub: Go to Settings → Actions → General → scroll to Workflow permissions → select Read and write permissions → Save.

Step 3

Automatic Daily Green Squares

GitHub will run the workflow daily, maintaining your 10 commits/day streak forever!

.github/workflows/commit-flow.yml YAML 
name: CommitFlow Auto Committer

on:
  schedule:
    # Runs automatically across the day
    - cron: '0 4,10,16,22 * * *'
  workflow_dispatch:
    inputs:
      commit_count:
        description: 'Number of commits to generate'
        required: true
        default: '10'
        type: string

permissions:
  contents: write

jobs:
  auto-commit:
    runs-on: ubuntu-latest
    steps:
      - name: 📥 Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: ⚙️ Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: 🔧 Configure Git Identity
        run: |
          git config --global user.name "${{ github.actor }}"
          git config --global user.email "${{ github.actor_id }}+${{ github.actor }}@users.noreply.github.com"

      - name: 🚀 Generate 10 Daily Commits
        env:
          COMMIT_COUNT: ${{ inputs.commit_count || '10' }}
        run: |
          node scripts/daily.js

      - name: 📤 Push to GitHub
        run: |
          git pull --rebase origin main || true
          git push origin main

GitHub Contribution Heatmap Rules & Troubleshooting

GitHub enforces 4 strict criteria before coloring squares green on your profile heatmap.

1

Git Author Email Must Match Your GitHub Account

GitHub matches commits to accounts by the author email. The email entered in CommitFlow must be listed under your GitHub Email Settings. If they don't match, GitHub treats commits as anonymous.

2

GitHub Personal Access Token (PAT) for Cloud / Render

When running on Render or any cloud server, git cannot prompt for passwords. You need a GitHub Personal Access Token with repo permissions. Add it in the top authentication bar or in Render as GITHUB_TOKEN.

3

Commits Must Be on the Default Branch (main)

GitHub only counts contributions on the repository default branch (e.g. main or master) or gh-pages branch.

4

Enable "Private Contributions" (If Repo is Private)

If your repository is private, visit your GitHub profile → click Contribution settings (dropdown directly above your heatmap) → check "Private contributions".

🚀 Render Deployment Environment Variables (Optional Setup)

If you have deployed this app on Render.com, you can set the following Environment Variables in your Render Dashboard (Environment tab) so authentication happens automatically:

GITHUB_TOKEN Your GitHub Personal Access Token (with repo scope)
GIT_REMOTE_URL https://github.com/your-username/your-repo.git
