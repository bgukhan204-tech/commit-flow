Step 1

Create Workflow File

Ensure .github/workflows/commit-flow.yml exists in your repository (Already created in this repo!).

Step 2

Enable Workflow Write Permissions

On GitHub: Go to Settings → Actions → General → scroll to Workflow permissions → select Read and write permissions → Save.

Step 3

Push & Relax

Push the code to GitHub. Your daily 10 commits will automatically trigger every day!

.github/workflows/commit-flow.yml YAML 
name: CommitFlow Auto Committer

on:
  schedule:
    # Triggers distributed throughout the day
    - cron: '0 4,10,16,22 * * *'
  workflow_dispatch:
    inputs:
      commit_count:
        description: 'Number of commits to generate'
        required: true
        default: '10'

permissions:
  contents: write

jobs:
  auto-commit:
    runs-on: ubuntu-latest
    steps:
      - name: 📥 Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: ⚙️ Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: 🚀 Generate 10 Daily Commits
        env:
          COMMIT_COUNT: ${{ inputs.commit_count || '10' }}
        run: |
          node scripts/daily.js

      - name: 📤 Push to GitHub
        run: |
          git pull --rebase origin main || true
          git push origin main

Why Contributions Turn Green (Official Rules)

GitHub has 4 strict rules for counting commits on your contribution calendar.

1

Git Email Must Match GitHub Account

The email used to author the commits must be added under your GitHub Email Settings. If they don't match, GitHub attributes commits to an anonymous user and will not color your graph.

2

Commits Must Be on the Default Branch

GitHub only counts contributions made on the repository's default branch (usually main or master) or the gh-pages branch.

3

Enable Private Contributions (If Repo is Private)

If your repo is private, go to your GitHub Profile → click Contribution settings (dropdown above the heatmap) → check "Private contributions".

4

Push Commits to Remote GitHub

Commits stored solely on your local hard drive are not visible to GitHub. Make sure to run git push origin main after generating them!
